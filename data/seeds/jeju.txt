# 제주도 큐레이션 장소 목록
#
# 이 파일을 고친 뒤 아래를 실행하면 web/data/places.json 이 다시 만들어집니다.
#
#     python3 scripts/build_places.py
#     TOUR_API_KEY=발급받은키 python3 scripts/build_places.py    # 사진·요약까지 채우려면
#
# ── 형식 ───────────────────────────────────────────────────────────
#   장소명 | 위도,경도 | 평점 | 한줄평
#
#   장소명만 필수이고 나머지 세 칸은 비워도 됩니다.
#   맨 앞이 [ ] 인 줄은 카테고리 구분, # 으로 시작하면 주석입니다.
#
# ── 좌표 ───────────────────────────────────────────────────────────
#   좌표가 없으면 거리 계산을 할 수 없어 그 장소는 목록에서 빠집니다.
#   채우는 방법은 두 가지입니다.
#
#   (1) TOUR_API_KEY 를 넣고 스크립트를 돌린다 → 관광공사 데이터에서 자동으로 채워집니다
#   (2) 직접 적는다 → 카카오맵(map.kakao.com)에서 장소를 우클릭 →
#       "좌표 복사" 를 누르면 위도, 경도 순서로 나옵니다. 그대로 붙여넣으면 됩니다
#
#   아래 목록은 장소명만 채워 둔 상태입니다. 좌표는 위 방법으로 채워 주세요.
#
# ── 평점·한줄평 ────────────────────────────────────────────────────
#   자동으로 수집하지 않습니다. 포털 평점을 긁어오는 것은 약관 위반 소지가 있어,
#   직접 다녀와서 매긴 점수와 메모를 적는 방식입니다. 비워두면 화면에 안 나옵니다.
#
#   예) 성산일출봉 | 33.4580,126.9427 | 4.6 | 새벽에 오르면 사람이 적다
#       (위 좌표는 형식을 보여주기 위한 예시이므로 직접 확인해 채우세요)
